# #СказалаДа! — свадебный портал

Сайт сказала-да.рф: каталог подрядчиков со скидками по дисконтной карте, личные кабинеты пар и партнёров, проверка карт по QR, Свадебный брокер и тендеры, Свадебный фестиваль 21 февраля 2027.

## Устройство
- `server/server.js` — сервер на Node.js 22 без внешних зависимостей: вход по email и паролю, сессии, база SQLite (`node:sqlite`), загрузка фото, хранилище документов с правами доступа на сервере, тарифы FREE / «Партнёр +», реклама и статистика, SOS, заказы и отзывы, миграции с резервной копией.
- `server/seo.js` — SEO-страницы: `/catalog/<раздел>/`, `/partners/<слаг>/`, `/broker/`, `/festival/`, `/free-dates/`, `/cooperation/`, серверный заголовок и контент, canonical, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`.
- `public/` — сайт. `public/index.html` собирается из исходника портала командой `python3 tools/build.py`.
- `src/server-mode.js` — подключение сайта к серверу (адаптер данных, вход, регистрация, инструменты организатора).
- `src/plus.js` — интерфейс v2 по ТЗ «Реклама, Партнёр + и Сотрудничество»: замки FREE, страница «Сотрудничество», заявка на подключение, «В центре внимания» и рекламные места, избранное, адресный запрос, календарь занятости, SOS, заказы и отзывы, панель организатора, человекочитаемые адреса.
- `seed/` — первичное наполнение каталога при первом запуске.
- `deploy/cloud-init.sh` — автонастройка сервера Ubuntu 24.04: Node.js, Caddy (HTTPS), служба, автообновление из GitHub каждые 2 минуты, ночные резервные копии.

## Запуск локально
```
DATA_DIR=./data ADMIN_EMAILS=you@example.com SECURE_COOKIE=0 node --no-warnings server/server.js
```
Сайт откроется на http://127.0.0.1:3000.

## Права доступа (сервер)
- Каталог виден всем; карточку меняет владелец или организатор.
- Профиль, карта и жалобы — только владелец и организатор.
- Заявка видна автору, организатору, приглашённым подрядчикам (брокер) и подрядчикам раздела (тендер). Фамилии, телефоны и избранное пары подрядчикам не отдаются.
- Отклик виден его автору, паре-владельцу заявки и организатору. Конкуренты чужих цен не видят.
- Проверка карты по номеру — только партнёрам с карточкой каталога, не чаще 60 раз в час.
- Публикация заявки — только через модерацию организатора; переходы статусов проверяет сервер.
- Организаторы задаются переменной `ADMIN_EMAILS`.

## Переменные окружения
- `ADMIN_EMAILS` — email организаторов через запятую.
- `PUBLIC_URL` — адрес сайта для canonical и sitemap (по умолчанию https://сказала-да.рф).
- `EVENT_SALT` — соль для обезличивания идентификатора сессии в статистике показов.

## Миграции
При старте сервер применяет новые миграции и перед этим делает копию базы в `DATA_DIR/backups/`. Миграция `2026-10-29-plus-ads-v2` создаёт настройки, тарифы, рекламные места, выдаёт действующим одобренным партнёрам пробный «Партнёр +» до 28.02.2027 и создаёт адреса карточек. Существующие карточки, карты, заявки, отклики, отметки и свободные даты не меняются.

## «Партнёр +» и права (ТЗ v2.1)
- FREE: карточка в каталоге и поиске, отзывы по подтверждённым заказам, базовая статистика. Скидка, тендеры, брокер, отклики, адресные запросы, SOS, календарь, свободные даты и проверка карт — только «Партнёр +».
- «Партнёр +» действует, только если есть активный срок и подтверждён допуск; скидка публикуется после утверждения условий организатором. Истечение срока — автоматически FREE, данные и архив сделок сохраняются.
- Все проверки — на сервере: прямые запросы без доступа получают отказ.
