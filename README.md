# #СказалаДа! — свадебный портал

Сайт сказала-да.рф: каталог подрядчиков со скидками по дисконтной карте, личные кабинеты пар и партнёров, проверка карт по QR, Свадебный брокер и тендеры, Свадебный фестиваль 21 февраля 2027.

## Устройство
- `server/server.js` — сервер на Node.js 22 без внешних зависимостей: вход по email и паролю, сессии, база SQLite (`node:sqlite`), загрузка фото, хранилище документов с правами доступа на сервере.
- `public/` — сайт. `public/index.html` собирается из исходника портала командой `python3 tools/build.py`.
- `src/server-mode.js` — подключение сайта к серверу (адаптер данных, вход, регистрация, инструменты организатора).
- `seed/` — первичное наполнение каталога при первом запуске.
- `deploy/cloud-init.sh` — автонастройка сервера Ubuntu 24.04: Node.js, Caddy (HTTPS), служба, автообновление из GitHub каждые 2 минуты, ночные резервные копии.

## Запуск локально
```
DATA_DIR=./data ADMIN_EMAILS=you@example.com SECURE_COOKIE=0 node --no-warnings server/server.js
```
Сайт откроется на http://127.0.0.1:3000.

## Права доступа (сервер)
- Каталог виден всем; карточку меняет владелец или организатор.
- Профиль, карта и жалобы — только владелец и организатор.
- Заявка видна автору, организатору, приглашённым подрядчикам (брокер) и подрядчикам раздела (тендер). Фамилии, телефоны и избранное пары подрядчикам не отдаются.
- Отклик виден его автору, паре-владельцу заявки и организатору. Конкуренты чужих цен не видят.
- Проверка карты по номеру — только партнёрам с карточкой каталога, не чаще 60 раз в час.
- Публикация заявки — только через модерацию организатора; переходы статусов проверяет сервер.
- Организаторы задаются переменной `ADMIN_EMAILS`.
